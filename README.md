# 🎮 مشروع لعبة كروت الوحوش - Monster Card Game

## 🌟 نظرة عامة على هيكل المشروع المنظم

تم تنظيم وهيكلة المشروع ليعمل بأعلى كفاءة، حيث تم فصل الملفات المشغلة باللعبة عن بيئات التدريب والمحاكاة والأرشيف:

```text
D:\deck game\
├── Game_Windows_Exe\                     # اللعبة التنفيذية الجاهزة للعب المباشر على ويندوز (.exe)
│   ├── MonsterCardGame.exe
│   └── MonsterCardGame_Data\
│
├── UnityGame\                            # مشروع محرك Unity الكامل (المشهد، السورس كود، والموارد)
│   ├── Assets\
│   ├── Packages\
│   └── ProjectSettings\
│
├── _Project_Archive_And_Offline_Tools\   # مجلد الأرشيف المستقل للأدوات الخارجية ومختبر التدريب
│   ├── Arena_Lab\                        # مختبر التدريب والـ RL ونقاط التفتيش (runs)
│   ├── Offline_Tools\                    # بيئة بايثون (venv) وموديلات وسكربتات المحاكاة
│   ├── Data_And_Reports\                 # التقارير وملف الإكسل الماستر لقاعدة البيانات
│   ├── Docs_And_Prompts\                 # البرومبتات، وثائق التصميم، والصور التوثيقية
│   └── Backups_And_Logs\                 # النسخ الاحتياطية وسجلات البناء القديمة
│
├── Build_Game.bat                        # سكربت فوري لبناء اللعبة عبر محرك Unity بنقرة واحدة
├── Play_Game.bat                         # سكربت فوري لتشغيل اللعبة مباشرة
├── ART_STYLE_GUIDE.md                    # دليل الهوية الفنية البصرية وقوالب توليد صور الكروت
├── SFX_STYLE_GUIDE.md                    # دليل كتابة برومبتات المؤثرات الصوتية لـ ElevenLabs
├── AGENTS.md                             # القواعد والإرشادات الهندسية للمشروع
└── README.md                             # هذا الدليل
```

---

## 🚀 كيفية تشغيل وبناء اللعبة

1. **لتشغيل اللعبة فوراً:**
   - شغّل الملف `Play_Game.bat` أو افتح `Game_Windows_Exe\MonsterCardGame.exe`.

2. **لإعادة بناء اللعبة بعد أي تعديل في Unity:**
   - شغّل الملف `Build_Game.bat`، وسيتم البناء آلياً خلال ثوانٍ وتحديث `Game_Windows_Exe`.

3. **للوصول لملف الإكسل الماستر أو تقارير التوازن:**
   - ستجدها منظمة داخل: `_Project_Archive_And_Offline_Tools\Data_And_Reports\`.
