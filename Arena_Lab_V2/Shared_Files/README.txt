Arena Lab V2 — Shared Drop Folder
=================================
Place any extra files you want to exchange between PC 1 (Main PC) and PC 2 (Training PC) here.

Meanwhile, all Arena Lab V2 trained AI models and match logs are saved automatically into:
  - ..\saved_models\   (40 model checkpoints + warm_start_base)
  - ..\logs\           (roster_stats.json, free10_latest_decks.json, card_stats.json, match_history.jsonl)
